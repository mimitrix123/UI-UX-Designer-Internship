# Week 3 — SaaS Dashboard Design System

## Mini Project
Create a reusable design system and 5-screen interactive SaaS dashboard prototype.

### Deliverables
- Design foundations: colors, typography, spacing, radius, elevation and accessibility.
- Reusable components: buttons, forms, tables, charts, navigation and modals.
- Five prototype screens: Dashboard, Analytics, Customers, Reports and Settings.
- Interaction specification covering navigation, modal animations, chart refresh, toggles and success toasts.

### Product
**PulseBoard** — a SaaS analytics dashboard for teams to understand business performance and customer health.

### Primary user flow
Dashboard → Analytics → Customers → Reports → Settings

### Tools
Figma for component library, variants, auto layout and prototype interactions.

### Prototype interaction principles
Use consistent 120–250ms transitions, clear focus states, meaningful feedback, and reduced-motion alternatives. See `prototype.md` for the complete interaction map.
