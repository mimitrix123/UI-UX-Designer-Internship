# Component Library

## Buttons
- Primary: high-emphasis action.
- Secondary: supporting action.
- Ghost: low-emphasis navigation/action.
- Danger: destructive action.
- Icon button: compact utility action with tooltip.

## Forms
- Input with label, placeholder, helper/error message.
- Select/dropdown with keyboard focus and selected state.
- Date range picker for dashboard filters.
- Checkbox/radio for discrete choices.
- Toggle for binary settings.

## Tables
- Header + sortable columns.
- Row selection and bulk actions.
- Status badges.
- Pagination and rows-per-page control.
- Loading skeleton and empty state.

## Charts
- KPI card for headline metrics.
- Line chart for trends.
- Bar chart for category comparison.
- Donut chart for composition.
- Tooltip and legend patterns.

## Navigation
- Workspace switcher.
- Sidebar navigation.
- Active/hover/focus states.
- Breadcrumbs for deep pages.
- User menu.

## Modals
- Dialog title and description.
- Form/content region.
- Secondary cancel action.
- Primary confirmation action.
- Destructive confirmation variant.

## Component naming convention
`Category / Component / Variant / State`

Examples: `Button / Primary / Default`, `Input / Text / Error`, `Table / Data / Loading`, `Modal / Confirmation / Open`.
