# Style Guide — ShopEase E-commerce Mobile App

## Brand
**ShopEase** — a clean, trustworthy mobile shopping experience for everyday products.

## Color palette
| Token | Hex | Use |
|---|---|---|
| Primary | #2563EB | CTAs, links, active states |
| Accent | #F59E0B | Ratings, offers, highlights |
| Text | #111827 | Headings and primary copy |
| Muted | #6B7280 | Secondary copy |
| Background | #F9FAFB | App background |
| Surface | #FFFFFF | Cards and sheets |
| Border | #E5E7EB | Dividers and input borders |
| Success | #16A34A | Delivered/success states |
| Danger | #DC2626 | Errors, destructive actions |

## Typography
Font: **Inter**.
- H1: 24px / 32px, Bold
- H2: 20px / 28px, SemiBold
- H3: 16px / 24px, SemiBold
- Body: 16px / 24px, Regular
- Small: 14px / 20px, Regular
- Caption: 12px / 16px, Regular
- Button: 14px / 20px, SemiBold

## Spacing
Base unit: **4px**. Use 4, 8, 12, 16, 24, 32, 40, 48px. Primary screen padding: 16px. Section gap: 24px.

## Components
- Buttons: 48px minimum height, 12px radius, strong contrast.
- Inputs: 48px height, 12px radius, visible label and focus state.
- Cards: 12px radius, 1px border, 16px internal padding.
- Product images: 1:1 ratio with neutral background.
- Bottom navigation: 64–72px high; five destinations: Home, Categories, Search, Wishlist, Profile.
- Touch targets: minimum 44×44px.

## Accessibility
Use readable contrast, never rely on color alone for status, provide clear labels, and keep destructive actions separated from primary actions.
