# User Flow — ShopEase

Home → Categories/Search → Product Detail → Add to Cart → Cart → Checkout → Order Confirmation → Orders.

Secondary paths:
- Product Detail → Wishlist
- Home/Search → Wishlist → Product Detail
- Profile → Orders / Wishlist / Settings
- Settings → Notifications / Privacy / Appearance

Primary UX goals: fast discovery, confident purchase decisions, low-friction checkout, and clear post-purchase tracking.
