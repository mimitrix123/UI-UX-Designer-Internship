# Week 2 — E-commerce Mobile App

**Project:** ShopEase mobile shopping experience  
**Role:** UI/UX Designer Internship

## Deliverables
10 core mobile screens:
1. Home
2. Categories
3. Product Detail
4. Cart
5. Checkout
6. Profile
7. Orders
8. Search
9. Wishlist
10. Settings

Also included: style guide, user flow, project overview, and Figma handoff guidance.

## Screen specification
- **01 Home:** personalized greeting, search, promotional banner, categories, recommended products, bottom navigation.
- **02 Categories:** category grid, subcategories, popular collections, bottom navigation.
- **03 Product Detail:** product image, title, rating, price, discount, variants, delivery information, wishlist, Add to Cart, Buy Now.
- **04 Cart:** selected products, quantity controls, remove/save actions, coupon field, price breakdown, checkout CTA.
- **05 Checkout:** delivery address, shipping option, payment method, order summary, total, Place Order CTA.
- **06 Profile:** avatar, name, membership, shortcuts to orders/wishlist, addresses, payment methods, and settings.
- **07 Orders:** order tabs by status, order cards, item count, amount, delivery date, tracking CTA.
- **08 Search:** search field, recent searches, filter/sort controls, product result grid/list.
- **09 Wishlist:** saved products, availability, price, remove action, Move to Cart CTA.
- **10 Settings:** account, notifications, appearance, privacy, security, help, and logout.

## Figma setup
Use a **390 × 844 px** mobile frame. Import `wireframes/10-screen-board.svg` as a visual reference, then recreate the frames with native Figma Auto Layout, components, and variants. Apply the tokens in `design/style-guide.md`.
