# UI/UX Designer Internship

This repository contains the internship project work for Weeks 1–4.

## Week 1 — Fitness Tracking App
UX research and low-fidelity wireframes covering personas, empathy maps, a user journey map, and five core screens.

## Week 2 — ShopEase E-commerce Mobile App
A complete e-commerce mobile app concept with 10 core screens and a reusable UI style guide covering typography, colors, spacing, components, and accessibility.

### Week 2 screens
1. Home
2. Categories
3. Product Detail
4. Cart
5. Checkout
6. Profile
7. Orders
8. Search
9. Wishlist
10. Settings

## Week 3 — PulseBoard SaaS Dashboard Design System
A reusable SaaS dashboard design system covering buttons, forms, tables, charts, navigation, modals, component states, accessibility, and a five-screen prototype specification with motion tokens.

### Week 3 screens
1. Dashboard
2. Analytics
3. Customers
4. Reports
5. Settings

## Week 4 — CareLoop Full UI/UX Case Study
A complete real-world UX case study from research to presentation: personas, empathy, journey mapping, competitive analysis, information architecture, wireframe specification, design system, 16 high-fidelity mobile screens, prototype flows, validation plan, and Behance/Dribbble presentation copy.

### Week 4 highlights
- Research-led problem definition
- 2 personas
- Journey map
- Competitive analysis
- Information architecture + flows
- Complete design system
- 16 high-fidelity screen concepts
- 3 prototype-ready key flows
- Accessibility and validation plan
- Portfolio-ready case-study narrative

SVG wireframes and high-fidelity boards are Figma-importable visual references. Recreate them as native Figma frames/components for a final interactive presentation.
