# Information Architecture & Flows

## Primary navigation
- Home
- Today
- Calendar
- Shared
- Documents
- Profile / Settings

## Core object model
`Care member → Tasks → Medications → Appointments → Documents → Activity`

## Key flows
### Medication
Home → Add medication → Details → Schedule → Reminder preference → Save → Medication detail

### Daily task
Home → Today → Task detail → Complete → Updated Today state

### Appointment
Home → Calendar → Appointment detail → Confirm attendance → Calendar state

### Shared responsibility
Home → Shared tasks → Add task → Assign person → Due date → Save → Confirmation

### Document
Home → Documents → Select document → Viewer → Share/permission control
