# CareLoop Design System

## Brand direction
Calm, warm, trustworthy, contemporary. Avoid clinical visual language and excessive data density.

## Color tokens
- Primary: `#2563EB`
- Primary Dark: `#1D4ED8`
- Accent: `#14B8A6`
- Ink: `#0F172A`
- Body: `#334155`
- Muted: `#64748B`
- Background: `#F8FAFC`
- Surface: `#FFFFFF`
- Border: `#E2E8F0`
- Success: `#16A34A`
- Warning: `#D97706`
- Danger: `#DC2626`
- Info: `#0284C7`

## Typography
Inter / system sans
- Display 28/36 Bold
- H1 24/32 Bold
- H2 20/28 SemiBold
- H3 16/24 SemiBold
- Body 16/24 Regular
- Small 14/20 Regular
- Caption 12/16 Regular
- Button 14/20 SemiBold

## Layout
- 4px base spacing
- Primary spacing scale: 4, 8, 12, 16, 24, 32, 40
- Mobile frame: 390 × 844
- Horizontal page padding: 20px
- Card radius: 16px
- Input/button radius: 12px
- Bottom-sheet radius: 24px
- Minimum touch target: 44 × 44px

## Components
Buttons, text fields, search, segmented controls, chips, tabs, cards, list rows, avatars, status badges, checkboxes, toggles, bottom sheets, dialogs, date picker, toast, empty states, loading skeletons, progress rings, timeline items.

## States
Default, hover, pressed, focus-visible, disabled, loading, success, error, selected.

## Accessibility
- Use labels in addition to icons.
- Never communicate status by color alone.
- Maintain readable contrast.
- Keep focus indicators visible.
- Support Dynamic Type / scalable text.
- Provide reduced-motion behavior.
- Keep interactive targets at least 44 × 44px.
