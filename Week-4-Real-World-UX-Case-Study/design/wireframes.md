# Low-Fidelity Wireframe Specification

All frames use a 390 × 844 mobile canvas with a 20px margin and an 8px spacing rhythm.

1. **Welcome:** brand mark, value proposition, primary CTA, privacy note.
2. **Sign in:** email, password, SSO option, help link.
3. **Home:** greeting, care-member switcher, Today card, upcoming appointment, quick actions.
4. **Add care member:** name, relationship, optional photo, sharing permissions.
5. **Member profile:** avatar, relationship, next task, medication and appointment shortcuts.
6. **Today:** date selector, grouped tasks, assignees, completion controls.
7. **Add medication:** name, dosage, frequency, start date, reminder, save.
8. **Medication detail:** schedule, next dose, adherence summary, edit action.
9. **Calendar:** month strip, appointments, filters.
10. **Appointment detail:** title, date/time, location, participant, notes, confirm CTA.
11. **Shared tasks:** assigned/unassigned tabs, task cards, add button.
12. **Documents:** folders, recent files, upload action, privacy indicator.
13. **Document viewer:** title, preview surface, metadata, permission action.
14. **Notifications:** grouped alerts, read state, preference shortcut.
15. **Insights:** weekly completion, upcoming workload, supportive summary.
16. **Settings:** profile, notifications, privacy, sharing, security, help.

## Wireframe rule
Prioritize hierarchy and flow before decoration: every screen has one dominant action and one clear next step.
