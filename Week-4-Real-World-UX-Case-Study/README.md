# Week 4 — Full UI/UX Case Study: CareLoop

**Problem:** People managing recurring household healthcare tasks often struggle to keep appointments, medicines, documents, and family responsibilities organized in one place.

**Solution:** **CareLoop** is a calm, privacy-conscious family care coordination app that combines reminders, shared tasks, appointments, documents, and progress into one simple experience.

## Deliverables
- UX research plan and findings
- 2 personas and empathy maps
- User journey map
- Competitive analysis
- Information architecture and user flows
- Low-fidelity wireframe specification
- Complete design system
- 16 high-fidelity mobile screens in an SVG board, importable into Figma
- Key-flow prototype and motion specification
- Professional Behance/Dribbble case-study presentation copy
- Accessibility and usability checklist

## 16 high-fidelity screens
1. Welcome
2. Sign in
3. Home dashboard
4. Add care member
5. Care member profile
6. Today / task list
7. Add medication
8. Medication detail
9. Appointment calendar
10. Appointment detail
11. Shared tasks
12. Documents
13. Document viewer
14. Notifications
15. Insights
16. Settings

## Primary prototype flow
`Home → Add medication → Medication detail → Today → Complete task → Home`

Secondary flows:
- `Home → Calendar → Appointment detail → Confirm`
- `Home → Shared tasks → Assign task → Confirmation`
- `Home → Documents → Document viewer`

## Figma handoff
The SVG board is a Figma-importable visual reference. For a native prototype, import the board and recreate each screen as a Figma frame, then connect the documented hotspots and transitions.

## Case-study narrative
**Discover → Define → Explore → Design → Prototype → Validate → Reflect**
