# High-Fidelity Screen Inventory

The CareLoop visual direction is applied consistently across 16 mobile screens. Each screen is specified at 390×844 for native Figma recreation.

| # | Screen | Primary goal | Key components |
|---:|---|---|---|
| 01 | Welcome | Explain value + trust | Logo, CTA, privacy note |
| 02 | Sign in | Authenticate | Inputs, primary button, recovery |
| 03 | Home | Orient user | Greeting, progress card, next task, quick actions |
| 04 | Add care member | Start shared profile | Avatar, fields, sharing panel |
| 05 | Member profile | See member overview | Avatar, next task, summary cards |
| 06 | Today | Execute daily work | Filters, task cards, completion controls |
| 07 | Add medication | Create reminder | Fields, recurrence, time control |
| 08 | Medication detail | Review schedule | Next dose, weekly adherence, edit |
| 09 | Calendar | Scan upcoming events | Month grid, event cards |
| 10 | Appointment detail | Confirm visit | Date/time, location, notes, CTA |
| 11 | Shared tasks | Coordinate ownership | Tabs, task cards, assignee/status |
| 12 | Documents | Find files | Search, folders, recent files |
| 13 | Document viewer | Read/share securely | Preview, metadata, permissions |
| 14 | Notifications | Triage updates | Alert cards, read states, preferences |
| 15 | Insights | Reassure with progress | KPI, trend chart, supportive copy |
| 16 | Settings | Control account/privacy | Profile, notifications, privacy, security |

## Visual QA checklist
- Consistent 20px page padding
- 16px card radius and 12px controls
- Inter typography hierarchy
- Primary blue used for actions, not decoration
- Teal used as a secondary supportive accent
- Status communicated through icon + label + color
- 44px minimum touch targets
- Consistent bottom navigation on task-oriented screens
