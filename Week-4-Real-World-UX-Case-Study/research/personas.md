# Personas

## Persona 1 — Priya, 29, self-manager
**Context:** Full-time professional managing recurring appointments and medications alongside work.

**Goals**
- Never miss an important task
- See only what needs attention today
- Add recurring reminders quickly

**Pain points**
- Too many disconnected reminders
- Calendar events lack task context
- Notifications become noisy

**Needs:** fast capture, contextual reminders, a trustworthy overview.

## Persona 2 — Arjun, 41, family coordinator
**Context:** Coordinates care tasks for a parent with help from siblings.

**Goals**
- Know who owns each task
- Share updates without repeated messages
- Keep important documents easy to find

**Pain points**
- Family members assume someone else handled a task
- Important files are scattered in chats
- Privacy boundaries are unclear

**Needs:** shared task ownership, activity visibility, permission controls.

## Empathy snapshot
| | Priya | Arjun |
|---|---|---|
| Says | “Just tell me what I need to do today.” | “I need to know who is handling what.” |
| Thinks | “I don't want another complicated app.” | “I shouldn't have to chase everyone for updates.” |
| Does | Uses phone calendar and notes | Uses group chat, calendar and cloud storage |
| Feels | Busy, occasionally anxious | Responsible, sometimes overwhelmed |
